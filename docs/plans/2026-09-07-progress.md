## Latest Tasks 09/11 runtime and recovery slice — 2026-09-07

Implemented bounded admission (default 100 pending jobs), bounded worker concurrency
(default two), exclusive POSIX worker ownership before recovery, and a shared
shutdown budget that retains ownership until old execution stops. API requests now
accept validated scan/stage budgets (defaults 300s/120s), persist them and forward
them to the orchestrator. Timing uses a monotonic clock. Spawned stages stop on
cancellation/deadline; Linux parent-death signaling and a parent sentinel watchdog
stop stages after abrupt worker loss. Process-start failure enters pipe cleanup.

Result, terminal status and completion event now commit atomically. Cancellation
wins over late success; repeated finalization does not overwrite terminal evidence.
Recovery records interrupted jobs/events while leaving queued jobs eligible to run.
SSE no longer duplicates the stored completion event with an extra snapshot.
